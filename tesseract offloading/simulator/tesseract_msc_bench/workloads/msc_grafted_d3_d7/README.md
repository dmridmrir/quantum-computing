# MSC grafted-code d3 to d7 workload

This fixture is generated by the pinned official Magic State Cultivation
implementation using `end2end-inplace-distillation`, uniform physical noise
`p=0.001`, CSS gates, Y basis, cultivation distance 3, and escape distance 7.

- `*.stim`: injection, cultivation, escape, and grafted matchable-code circuit
- `model.dem`: undecomposed detector error model using Tesseract's DEM options
- `syndromes.01`: 64 postselection-surviving detector-event samples
- `observables.01`: corresponding actual observable flips
- `metadata.json`: source/DEM hashes, postselection counts, raw indices, and
  syndrome weights

The postselection detector set is reproduced from the official cultivation
desaturation sampler, including coordinate annotations and the extra
single-basis two-detector observable-flip rule. Shot 50 is the smallest
nonzero syndrome in this deterministic sample and is used for the checked-in
Tesseract DPU trace.
